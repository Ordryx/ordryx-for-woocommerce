# Security

Found a security problem in the plugin, or in what it talks to (Ordryx's
server at account.ordryx.com, or an Ordryx)? Tell us at
**security@ordryx.com**, never in a public issue. The same address is
published at <https://ordryx.com/.well-known/security.txt>.

Please say what you found, how to see it happen, and which version of the
plugin (WooCommerce › Settings › Ordryx shows it, as does the Plugins
screen). We answer within a few days, and say when it's fixed.

We won't take action against you for a report made in good faith that keeps
to these rules: report it to security@ordryx.com, give us reasonable time to
fix it before telling anyone else, don't reach other people's data beyond
what shows the problem, and don't disrupt Ordryx or anyone's store. (The
same rules as section 6 of Ordryx's terms, <https://ordryx.com/terms>.)

Only the newest version is fixed: update to it
(<https://ordryx.com/woocommerce>).
